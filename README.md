# Spendly

A responsive multi-page student expense management web application built with HTML, CSS and JavaScript.

## Features

- User registration and login demo
- Dashboard with total, monthly and remaining-budget summaries
- Add, view and delete expenses
- Search and category filtering
- Expense sorting by date and amount
- Monthly budget tracking with progress indicator
- Category-wise spending analytics
- Profile management
- Persistent browser storage using LocalStorage
- Responsive sidebar and mobile-friendly layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Run Locally

Open `index.html` in a browser, or use VS Code Live Server.

> This is a frontend project. Authentication and data storage are implemented with browser LocalStorage for learning/demo purposes; no backend database is used.
